# Does an Antitrust Collusion Test Work on AI Agents?

Sam Deegan, Nate Maximiano · Apart Research AI Collusion Research Sprint, October 2026

We adapt a collusion detection method called exchangeability, put forward by Bajari and Ye, to measure its effectiveness on an LLM agent bidding environment. Ultimately, we demonstrate that features of realistic LLM agents, like memory, cause violations of the necessary test assumptions, yielding a false positive rate of 32.2% on a control condition. We believe researchers should consider how LLM environments affect the assumptions that make information-theoretic methods viable.
